**# Pricing Cards**

A responsive pricing cards component built using HTML5 and CSS3. This project focuses on using Flexbox, the CSS box model, spacing, typography hierarchy, and interaction states to create a reusable pricing comparison layout.

**## 📁 Project Structure**

**## 🚀 Features**

* Three pricing cards displayed in a row
* Consistent card styling and equal heights
* Recommended middle plan with visual emphasis
* Plan name, price, tagline, and feature list
* Call-to-action button for each pricing plan
* Flexbox-based card layout
* Proper spacing using padding and gap
* Clear typography hierarchy
* Button hover and focus states
* Responsive layout for different screen sizes
* Reusable pricing card structure

**## 🛠️ Technologies Used**

* HTML5
* CSS3

**## 📚 Learning Outcomes**

* Build reusable pricing card components
* Understand and apply the CSS box model
* Use Flexbox to create horizontal layouts
* Create equal-height cards with aligned buttons
* Use `gap` for consistent spacing between sibling elements
* Create visual emphasis for a featured card
* Establish a clear typography hierarchy
* Implement hover and focus interaction states
* Build responsive layouts using CSS
* Understand how HTML and CSS can be structured for future JavaScript enhancements
