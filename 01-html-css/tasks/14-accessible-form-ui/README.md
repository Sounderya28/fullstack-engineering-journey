# Accessible Form UI

An accessible and responsive form UI built using **HTML5 and CSS3**. This project focuses on creating a clean and user-friendly form with proper labeling, required fields, keyboard focus states, password fields, error message placeholders, and accessibility considerations.

## 📁 Project Structure

```text
14-accessible-form-ui/
│
├── assets/
│   ├── favicon.ico
│
├── output.png
├── index.html
├── styles.css
└── README.md
```

## 🚀 Features

- Accessible form structure using semantic HTML
- Full name field
- Email field with native email validation
- Password field
- Confirm password field
- Proper `<label>` elements associated with form controls
- Required field validation using HTML5 `required`
- `aria-required` attributes for required fields
- Password visibility eye icon UI
- Error message placeholders
- Visible keyboard focus states
- Responsive form layout
- CSS styling with attention to usability and accessibility
- Clean and simple form design

> **Note:** The password visibility icon is currently a static UI element because this project is implemented using HTML and CSS only. Actual password show/hide functionality requires JavaScript.

## ♿ Accessibility Considerations

- Form controls have associated labels
- Required fields use the native HTML `required` attribute
- `aria-required="true"` is provided for required fields
- Input focus states are visually indicated
- Semantic HTML elements are used throughout the form
- Error message areas are included for validation feedback
- The password eye icon is treated as a visual element rather than a functional control since JavaScript is not used
