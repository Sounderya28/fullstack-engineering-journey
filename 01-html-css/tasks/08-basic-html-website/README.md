# Basic HTML Website

A simple multi-page website built using HTML5 and CSS. This project demonstrates semantic HTML, multiple web sections, navigation, SEO meta tags, and a contact form.

## 📁 Project Structure

```text
08-basic-html-website/
├── assets/
│   └── favicon.ico
├── output.png
├── index.html
├── styles.css
└── README.md
```

## 🚀 Features

- Semantic HTML5 structure
- Multi-section website layout
- Navigation bar across all sections
- Homepage, Projects, Articles, and Contact sections
- Contact form with Name, Email, and Message fields
- SEO meta tags
- Favicon support
- Basic CSS styling

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 Learning Outcomes

- Build a semantic HTML website
- Create a multi-page website structure
- Add SEO meta tags
- Create HTML forms
- Organize project files for scalability
- Prepare the website for responsive styling
