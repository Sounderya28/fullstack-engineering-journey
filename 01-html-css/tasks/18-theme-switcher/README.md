**# Theme Switcher with CSS Variables**

A theme switcher component built using HTML5 and CSS3 that allows users to switch between multiple visual themes without JavaScript. This project focuses on CSS variables, design tokens, radio inputs, and CSS state selectors to dynamically change the appearance of a shared preview card.

**## 📁 Project Structure**

```text
18-theme-switcher/

├── assets/
│   └── favicon.ico
├── output.png
├── index.html
├── styles.css
└── README.md
```

**## 🚀 Features**

- Three different theme options
- Light, dark, and custom theme variants
- CSS custom properties used as design tokens
- Theme switching without JavaScript
- Radio inputs with accessible labels
- Keyboard-accessible theme controls
- Shared preview card for all themes
- Dynamic theme changes using CSS state selectors
- Consistent token names across all themes
- Card heading, paragraph, and button elements
- No hardcoded colors outside the CSS token layer
- Responsive and reusable UI structure

**## 🛠️ Technologies Used**

- HTML5
- CSS3
- CSS Custom Properties (Variables)

**## 📚 Learning Outcomes**

- Understand CSS custom properties and design tokens
- Define reusable variables using `:root`
- Create multiple theme variants using CSS variables
- Switch themes using radio inputs and CSS selectors
- Understand the `:has()` pseudo-class and sibling selectors
- Build keyboard-accessible theme controls
- Reuse the same HTML structure across multiple themes
- Avoid hardcoded colors by organizing styles around design tokens
- Create themeable components without JavaScript
