# Single-Page HTML CV

A simple single-page CV built using HTML5 and CSS. This project demonstrates semantic HTML, SEO meta tags, Open Graph (OG) tags, and a favicon.

https://roadmap.sh/projects/single-page-cv

## 📁 Project Structure

```
07-single-page-cv/
├── assets/
│   └── favicon.ico
├── output.png
├── index.html
├── styles.css
└── README.md
```

## 🚀 Features

- Semantic HTML5 structure
- Single-page CV layout
- Skills, Education, and Experience sections
- SEO meta tags
- Open Graph (OG) tags
- Favicon support
- Basic CSS styling

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 Learning Outcomes

- Build a semantic HTML webpage
- Organize content into sections
- Add SEO and Open Graph metadata
- Link a favicon
- Prepare the webpage for further styling
