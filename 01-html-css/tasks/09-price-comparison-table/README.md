# Pricing Comparison Table

A simple pricing comparison page built using a semantic and accessible HTML table. This project focuses on proper table structure, accessibility, semantic page elements, and HTML metadata without using CSS styling.

## 📁 Project Structure

```text
08-pricing-comparison-table/
├── assets/
│   └── favicon.ico
├── output.png
├── index.html
├── styles.css
└── README.md
```

## 🚀 Features

- Semantic HTML5 page structure
- Header, main, and footer sections
- Accessible HTML pricing comparison table
- Table caption describing the comparison
- `<thead>` and `<tbody>` for structured table data
- `scope="col"` for column headers
- `scope="row"` for plan-name row headers
- `colspan` or `rowspan` for meaningful merged cells
- Proper HTML metadata
- No CSS styling, focusing on HTML structure and accessibility

## 🛠️ Technologies Used

- HTML5

## 📚 Learning Outcomes

- Understand when to use HTML tables for structured data
- Build accessible tables using semantic HTML
- Use `<caption>`, `<thead>`, and `<tbody>` correctly
- Understand the purpose of `scope="col"` and `scope="row"`
- Use `colspan` and `rowspan` appropriately
- Structure a webpage using semantic HTML5 elements
- Add essential HTML document metadata
