**# Tooltip Navigation**

A simple navigation tooltip component built using HTML5 and CSS3. This project focuses on creating interactive tooltips that appear above navigation items when hovered, using CSS positioning, hover effects, and transitions without JavaScript.

**## 📁 Project Structure**

16-tooltip-ui/

├── output.png
├── index.html
├── styles.css
└── README.md

**## 🚀 Features**

- Navigation menu with multiple items
- CSS-only tooltip functionality
- Tooltips displayed above navigation items
- Hover effects for navigation elements
- CSS positioning for tooltip placement
- Smooth transitions and visual effects
- No JavaScript required
- Responsive navigation layout
- Clean and reusable tooltip structure

**## 🛠️ Technologies Used**

- HTML5
- CSS3

**## 📚 Learning Outcomes**

- Create tooltips using HTML and CSS
- Understand CSS positioning techniques
- Use `position: relative` and `position: absolute`
- Create hover-based UI interactions
- Use CSS transitions for smooth visual effects
- Position elements relative to their parent elements
- Build interactive components without JavaScript
