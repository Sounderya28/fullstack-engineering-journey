**# Contact Form**

A simple accessible contact form built using HTML5. This project focuses on proper form structure, real labels, grouped controls, browser validation, form submission attributes, and HTML metadata without using JavaScript or CSS styling.

**## 📁 Project Structure**

```text
09-contact-form/

├── assets/
│   └── favicon.ico
├── output.png
├── index.html
├── styles.css
└── README.md
```

**## 🚀 Features**

- Semantic HTML5 form structure
- Accessible labels for every form control
- Full name, email, subject, and message fields
- Subject selection using `<select>` and `<option>`
- Radio button group using `<fieldset>` and `<legend>`
- Optional newsletter subscription using a checkbox
- Browser-side validation using `required`, `type="email"`, and `minlength`
- Form submission using `action` and `method="post"`
- Submit button with clear text
- Proper HTML metadata
- Form controls configured with `name` and `value` attributes for server submission

**## 🛠️ Technologies Used**

- HTML5

**## 📚 Learning Outcomes**

- Build an accessible HTML contact form
- Associate labels with form controls using `for` and `id`
- Understand how form controls use `name` and `value` pairs during submission
- Group related controls using `<fieldset>` and `<legend>`
- Use `<select>`, `<textarea>`, radio buttons, and checkboxes correctly
- Apply browser validation using HTML attributes
- Understand the difference between browser validation and server-side validation
- Understand how form data is submitted as an HTTP request
- Add essential HTML document metadata
