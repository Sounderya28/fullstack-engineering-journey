**# Image Grid Layout**

A responsive image grid layout built using HTML5 and CSS3. This project focuses on practicing CSS Grid to arrange multiple images into a clean, flexible, and responsive layout that adapts to different screen sizes.

**## 📁 Project Structure**

```text
15-image-grid-layout/

├── assets/
│   └── favicon.ico
├── output.png
├── index.html
├── styles.css
└── README.md
```

**## 🚀 Features**

- Responsive image grid layout
- CSS Grid-based page structure
- Six images arranged in a structured grid
- Responsive layout for different screen sizes
- Proper spacing between grid items
- Image sizing and alignment using CSS
- Clean and flexible grid structure
- Images adapt to the available container space
- Accessible images with descriptive `alt` text

**## 🛠️ Technologies Used**

- HTML5
- CSS3

**## 📚 Learning Outcomes**

- Understand the fundamentals of CSS Grid
- Create grid containers with rows and columns
- Position and arrange elements within a CSS Grid
- Control spacing between grid items using `gap`
- Create responsive layouts using CSS media queries
- Understand how grid layouts adapt to different screen sizes
- Practice alignment and sizing of grid items
- Build flexible and visually appealing image layouts
